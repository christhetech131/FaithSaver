Image guidelines

  • Landscape orientation preferred (16:9 works best)
  • Minimum size 1920×1080
  • Formats: JPG or PNG
  • Color: sRGB, non-progressive, 8-bit
  • Attribution: include your name in filename (optional)

Licensing & permissions

By uploading, you affirm you own the rights (or have permission) to share the image and grant FaithSaver permission to display, crop, and resize it across Roku devices. If you submit a raw photo, you also permit us to add scripture text and export a finished derivative for display.

Quick summary

  • Finished = verse already on image → faster approval.
  • Raw = photo only → we add verse before publishing.
  • Use category__title__name.ext naming if you want to help us sort.

About FaithSaver

FaithSaver is a Roku screensaver that shows faith-based images. The production saver pulls approved images directly from this GitHub repository (by category) and shuffles them on each run. Preview mode is offline-only.

Categories: animals, fall, geology, scenery, space, spring, summer, textures, winter, seasonal.
