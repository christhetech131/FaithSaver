# Store Listing (Description)

## Short description
A lightweight, privacy-friendly screensaver that displays beautiful, faith-based images with smooth transitions and simple category settings.

## Full description
FaithSaver is a Roku screensaver that rotates curated, faith-based photography and Scripture artwork. It starts instantly with an offline image and then displays online images from a public GitHub repository. Choose your favorite category in **Settings ▸ Theme ▸ Screensavers ▸ Change screensaver settings**. No accounts, no analytics—just images.

### Features
- Smooth transitions: Fade (first), then Fade/Slide/Zoom every ~30 seconds  
- Simple settings: Animals, Fall, Geology, Scenery, Seasonal, Space, Spring, Summer, Textures, Winter  
- Offline-first: immediate display with graceful network fallback  
- Privacy-friendly: no tracking or analytics  
- Lightweight and reliable

### Requirements
- **Minimum firmware:** Roku OS **9.0+** recommended for full online functionality (HTTPS to GitHub).  
- Internet connection required for online images; an offline image is included as a fallback.
